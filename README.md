`SillyTavern/data/<你的用户目录>/extensions/`

- “Amily2角色总集”常驻条目与已更新楼层记录

## 编辑角色生成提示词

在酒馆右侧“扩展”面板展开“角色世界书（系统 API 版）”，即可看到“角色信息生成提示词”区域。这里可以直接编辑前置系统提示词、全量生成提示词和增量融合提示词；输入内容会自动保存，下一次点击更新时生效。字段定义和输出格式也包含在全量/增量提示词中，可以直接一并修改。点击“恢复默认提示词”可撤销自定义内容。

## 多故事线世界书

勾选“自动分配到对应故事线世界书”后，插件会扫描酒馆中的世界书，根据条目关键词和内容中的 `name` 字段识别角色归属。生成的角色档案会写入对应世界书中的独立 `CWB:自动档案` 条目，不覆盖原有手工角色设定。若同名角色存在于多本世界书，可在“手动角色绑定”中填写 JSON 覆盖自动识别，例如 `{"许亦宁":"故事线01"}`。新增或导入故事线世界书后，点击“扫描世界书角色归属”即可刷新识别结果。

启用多世界书路由后，插件还会在当前角色卡绑定的主世界书中维护一个 `CWB角色世界书档案目录-聊天ID` 条目。目录只记录角色名、所属故事线世界书和自动档案位置，供模型快速定位，不会复制完整角色档案。

v0.5 默认提示词只维护三类信息：`SEX` 性经历事实摘要与次数、`DY/REL` 对用户的好感度等动态数值及变化依据、`PL` 当前剧情条目。外貌、服装、性格、背景、语言风格、身体细节等静态字段不再生成。所有提示词仍可在插件设置中继续编辑。

用户主角使用 `[record_type]:USER` 独立输出，并固定保存到当前角色卡绑定的主世界书中。所有自动生成档案统一按 `动态-名字` 命名，例如 `动态-许亦宁`、`动态-赵冠宇`。主角档案维护自身状态、目标、能力、资源、经历、关系网络和参与的剧情条目，不参与普通角色的故事线世界书路由。

启用插件后，“角色档案”按钮固定显示在酒馆顶部设置图标栏的最右侧，位于扩展（方块）图标之后，点击即可查看、编辑或删除当前聊天的自动档案。

## API 行为

内部使用 SillyTavern 原生 `generateRaw()`，因此会沿用当前主 API、当前模型、采样预设和 instruct 状态。插件只允许可选地限制最大回复 Token，不保存任何 API 密钥。
## 0.10.5 时间线同日合并

- 时间线统一为“日期｜事件”，同一天关键进展合并记录，日期只出现一次。
- 不再单列出场角色；旧格式兼容并在合并时规范化去重。
- 刷新默认、组合及已保存的自定义时间线提示词。

## 0.10.6 刷新后恢复已确认进度

- 读取新版模块进度时，同时合并旧版经角色档案、时间线与关系记录交叉确认的完成范围。
- 明确标记的失败楼层仍保留为待补，不会被旧成功范围覆盖。

## 0.10.7 插件参考条目不再注入

- 时间线、角色关系汇总和档案目录仅供插件内部读取，创建或更新时设为禁用注入。
- 切换聊天时也会关闭旧版参考条目的注入；角色档案与用于剧情召回的角色总集保持原逻辑。
